# بانک آریا — نمای ۳۶۰ درجه مشتری و تحلیل ریزش (Customer 360° & Churn)

یک نمونه‌کار مهندسی داده و هوش تجاری (Power BI + Streamlit Preview) به زبان فارسی و راست‌چین (RTL)، مبتنی بر دادهٔ واقعی عمومی (`Churn_Modelling.csv`) که با حفظ ۱۰۰٪ سیگنال‌های آماری، توزیع‌ها و هم‌بستگی‌ها به مدل ستاره‌ای بومی‌سازی‌شده تبدیل شده است.

---

## ۱. تعریف مسئله و مأموریت پروژه

در بانکداری خرد و تجاری، شناخت جامع مشتریان (**Customer 360°**) و شناسایی عوامل کلیدی خروج مشتریان (**Churn Drivers**) زیربنای تصمیم‌گیری در حوزهٔ نگهداشت مشتری و مدیریت سبد محصولات است. این پروژه یک بستهٔ کامل تحلیلی برای بانک فرضی **«بانک آریا»** ارائه می‌دهد که شامل موارد زیر است:

1. **پایپ‌لاین بازتولیدپذیر داده (`scripts/build_data.py`):** تبدیل قطعی (Deterministic) دیتاست ۱۰٬۰۰۰ ردیفی `Churn_Modelling.csv` به ۶ جدول مدل ستاره‌ای با تقویم شمسی پیوسته (`jdatetime`) و واحد ریال نمایشی.
2. **مدل ستاره‌ای استاندارد (`model/MODEL.md` و `assets/model_diagram.svg`):** چهار جدول بُعد (`dim_date`, `dim_customer`, `dim_branch`, `dim_product`) و دو جدول فکت (`fact_snapshot`, `fact_product_holding`).
3. **لایه محاسباتی DAX و تم گرافیکی Power BI (`model/measures.dax`, `report/theme.json`, `report/POWER_BI_BUILD_GUIDE.md`):** آماده برای ساخت سریع فایل `.pbix` در Power BI Desktop با تم سبز و طلایی «Bank Aria Fa» (`#0b6e4f` / `#d4a017` روی `#f7faf7`).
4. **اپ پیش‌نمایش تعاملی ۵ صفحه‌ای (`app.py`):** داشبورد زندهٔ Streamlit با فونت محلی `Vazirmatn FD`، راست‌چین کامل، بدون هیچ درخواست شبکه در زمان اجرا، و مجهز به ۱۵ تست خودکار (`tests/test_data_quality.py`).

## ۳. یافته‌ها و شاخص‌های کلیدی داده (تاریخ مرجع: ۱۴۰۳/۱۲/۲۹)

* **جمعیت کل مشتریان:** `۱۰٬۰۰۰` مشتری یکتا (`۷٬۹۶۳` نفر مانده / وفادار معادل **۷۹٫۶۳٪**؛ `۲٬۰۳۷` نفر ریزش‌کرده معادل **۲۰٫۳۷٪**).
* **مانده سپرده‌ها (مقیاس نمایشی `×۲۵۰٬۰۰۰` ریال):** کل مانده `۱۹۱٬۲۱۴٬۷۲۳٬۲۲۰٬۰۰۰` ریال (~۱۹۱٫۲۱ همت نمایشی)؛ میانگین هر مشتری `۱۹٬۱۲۱٬۴۷۲٬۳۲۲` ریال؛ سهم مشتریان با مانده صفر: **۳۶٫۱۷٪** (`۳٬۶۱۷` نفر).
* **تحلیل استانی (نگاشت ۱:۱ از کشور منبع):**
  - **تهران (`France`):** `۵٬۰۱۴` مشتری | نرخ ریزش: **۱۶٫۱۵٪** (`۸۱۰` نفر)
  - **اصفهان (`Germany`):** `۲٬۵۰۹` مشتری | نرخ ریزش: **۳۲٫۴۴٪** (`۸۱۴` نفر — *ویژگی دادهٔ آلمان در منبع اصلی، نه اقتصاد واقعی اصفهان*)
  - **خراسان رضوی (`Spain`):** `۲٬۴۷۷` مشتری | نرخ ریزش: **۱۶٫۶۷٪** (`۴۱۳` نفر)
* **الگوی U-شکل تعداد محصولات (`NumOfProducts` — میانگین `۱٫۵۳` محصول):**
  - **۱ محصول (`۵٬۰۸۴` نفر):** نرخ ریزش **۲۷٫۷۱٪**
  - **۲ محصول (`۴٬۵۹۰` نفر):** نرخ ریزش **۷٫۵۸٪** (پایدارترین گروه مشتریان)
  - **۳ محصول (`۲۶۶` نفر):** نرخ ریزش **۸۲٫۷۱٪**
  - **۴ محصول (`۶۰` نفر):** نرخ ریزش **۱۰۰٫۰۰٪**
* **نقش فعالیت مشتری (`IsActiveMember`):** سهم اعضای فعال **۵۱٫۵۱٪** است؛ نرخ ریزش در اعضای فعال **۱۴٫۲۷٪** و در اعضای غیرفعال **۲۶٫۸۵٪** (نزدیک به دو برابر) است.

## ۴. راهنمای اجرا و بازتولید

### الف) بازتولید جداول داده از فایل خام
```bash
cd project_01_banking_customer_360
python3 scripts/build_data.py
```

### ب) اجرای ۱۵ تست خودکار کیفیت داده و تست ۵ صفحه اپ
```bash
cd project_01_banking_customer_360
python3 -m unittest discover -s tests -v
```

### ج) اجرای زنده اپ پیش‌نمایش Streamlit روی پورت ۸۵۰۲
```bash
cd project_01_banking_customer_360
streamlit run app.py --server.port 8502 --server.address 0.0.0.0
```

## ۵. اصول صداقت تحلیلی و محدودیت‌ها (خلاصهٔ `LIMITATIONS.md`)

1. **مقیاس ریالی نمایشی:** مبالغ ریالی حاصل ضرب ثابت `×۲۵۰٬۰۰۰` در ارقام منبع هستند و ریال واقعی بانک نیستند.
2. **عدم تعمیم جغرافیایی:** نرخ ریزش ۳۲٫۴۴٪ در «اصفهان» ویژگی زیرجامعهٔ آلمان در دیتاست `Churn_Modelling.csv` است و نباید به شرایط اقتصادی استان اصفهان نسبت داده شود.
3. **مشتق بودن `fact_product_holding`:** شمار کل محصولات هر مشتری از منبع آمده، اما ریزِ نوع محصول و تاریخ بازگشایی با `seed` ثابت مشتق شده است.
4. **بدون فایل `.pbix` و بدون ادعای ROI:** این پروژه فاقد فایل باینری `.pbix` است (راهنمای کامل ساخت در `report/POWER_BI_BUILD_GUIDE.md` قرار دارد) و هیچ ادعایی دربارهٔ کاهش ریزش واقعی یا بازگشت سرمایه (ROI) مطرح نمی‌کند.
